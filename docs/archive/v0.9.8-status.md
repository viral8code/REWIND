# REWIND v0.9.8 実装状況

2026-10-01。compiler/package/language 0.9.8。3moduleを追加した。

- csv: bounded UTF-8 CSV parse/format、Tableのrows/width/get。最大65,536 byte/field数、4,096 row。comma、double quote escape、quoted newline、LF/CRLFを扱い、裸のCR・閉じ忘れ・quote後のtext・UTF-8不正を拒否する。CsvError.positionは検出位置で、field decode失敗はdelimiter/EOF位置。formatは全fieldをquoteしLFを付ける。streaming CSVではない。
- matrix: 最大128×128のchecked Int64 create/get/multiply/power。dimension/negative exponent/overflowをResultで返す。返却用ownerを新しく作り、入力を変えない。
- dp: strict LIS length、0/1 knapsack。最大65,536要素/LIS、4,096 item・65,536 capacity/knapsack。weight0はitem一回、負weightを拒否し加算overflowを検出する。

modular.inverseを係数をmodulus内に保つEuclidへ変更し、正のInt64全域で中間係数overflowを避ける。非可逆を区別する。immutable scalar fieldをコピーして新ownerのconstructorへ渡せるようにし、borrowed mutable payloadを直接返す拒否規則は維持する。

CSV quote/Unicode/newlineのroundtripと不正形式、Fibonacci行列power、LIS重複、weight0 knapsack、full-width inverse、借用escape拒否を検証した。CSV絶対診断位置の詳細化・incremental CSV、decimal/日時、network/storeなどは未完了。算法の大きい入力にはstep/workと履歴memoryの上限がある。
