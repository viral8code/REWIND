# REWIND 4.2.0

Int のビット演算子、一時的な値の借用、GUI の円と時間つきの入力待ちを追加しました。4.1.0 のプログラムは、そのまま動きます。

- 言語: `Int` で `&`、`|`、`^`、`<<`、`>>` が使えます。一時的な値を `&` で貸せます。
- GUI: 円（楕円）の描画、ウィジェットの位置と色の変更、時間つきの入力待ちを追加しました。
- 実行: ごみ集めの費用を別枠で数えます。整数の `match` を速くしました。GUI の記録が、大きな画面でも止まりません。

詳細は[言語リファレンスの付録 B](../language-reference.md#420-の変更)を参照してください。
