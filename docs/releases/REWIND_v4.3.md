# REWIND 4.3.0

ビットボードを書く利用者からの報告をもとに、`Int` の演算と GUI の入力待ちを直しました。4.2.x のプログラムは、そのまま動きます。

- 言語: 論理右シフト `>>>` とビット反転 `~` を追加しました。最上位のビットが立つ 16 進のリテラルを書けます。
- 標準: `Int` に、折り返す算術とビット数を数えるメソッドを追加しました。
- GUI: `nextEvent` と `waitEvent` を混ぜても、記録の `idle` で止まりません。

詳細は[言語リファレンスの付録 B](../language-reference.md#430-の変更)を参照してください。
