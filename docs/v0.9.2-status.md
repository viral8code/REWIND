# REWIND v0.9.2 実装状況

更新日: 2026-10-01。compiler/package 0.9.2、language 0.9.2、branch `codex/rewind-v0.9.2`。[v0.9.2仕様](REWIND_v0.9.2.md)の初回実装単位を採用する。

## SDK

`sdk-build --output NEW_DIRECTORY --key SEED`、`sdk-verify --sdk DIRECTORY --public-key KEY`、`sdk-install --root PROJECT --sdk DIRECTORY --public-key KEY` を実装した。Linux x86_64 を対象に current binary、12のstd module source、contract tests、module API文書/snapshot、CLI/JSON保存例、MIT/依存ライセンス、Cargo.lockを配置する。秘密鍵・cache・trace・mutable stateは配布に含めない。

組立て時にstdの5契約テストを実行する。各moduleを入口にAPI snapshotを生成し、std-api.jsonを索引にする。署名manifestはSHA-256、size、実行権限、target、compiler/language/stdの版を固定する。SDK署名はpackage/app release/artifactと異なるEd25519 domain。verificationはcallerが指定した公開鍵を使い、std package署名も確認する。

512 file/256 MiB、directory深さ64/数1,024、manifest/signature各1 MiB。symlink・非通常ファイル・改変/追加/欠落・版/target不一致を拒否する。既存出力directoryを上書きしない。同じbinary/seedの二回の組立てでmanifestとsignatureの一致を検証する。binaryの完全再現ビルド、archive、公式SDK公開、runtime-only binary、他targetは未実装。

stdは署名付きdependencyとしてproject内vendorへ明示導入する。exact version/signature/trust/source digestをmanifest/lockへ固定する。namespace/signing alias/destinationの衝突は拒否し、失敗時はmanifest/lockと新規コピー先を復元する。通常実行がSDKの場所に依存しない。自動探索、自動trust、自動upgradeを行わない。

## ライブラリと型

text/bytes/number/bits/result/mapを追加し、collectionsへfold/find/count、mathへmulModを追加した。所有権・効果・位置/予算/失敗/順序の契約は[ライブラリ一覧](../libraries/README.md)。native primitiveはpureで、StdErrorはimmutable `{code:String,offset:Int}`。設定schema/JSON保存は既存config/args/jsonを利用する。

Option/Resultは内包型に従ってShare/Sendを判定する。annotated bindingの型をownership検査でも保持する。Resultの存在しない分岐の型引数は、型検査したgeneric callの具体的な型引数をbytecodeに残す。import・nested generic・match・closure captureとcacheを扱う。generic Frozen collectionからのscalar読取り/thawも補修した。mutable payloadの複製を許可しない。

StdErrorのreserved layout/native nameはsourceとartifact検証で保護する。0.2〜0.9.1のlanguage modeを保持する。artifact/replay/secure lockのcompilerはexact 0.9.2を要求するため、更新時にupdate/rebuild/再記録が必要。旧v0.9.1 std contractは固定fixtureで回帰検証する。

## 検証と残る範囲

既存169件にv0.9.2の4件を追加し、合計173件のRust回帰テストを検証した。Unicode scalar/byte、UTF-8の不正位置、Int最小値/overflow/radix、finite Float、shift、mulMod、codec上限、generic/ownership、cacheとsource-free artifactを確認する。SDKは二回の組立て、署名/改変/衝突/symlink、std import、stdinのCLI、record/replay、asset付きproduction installとrelease署名、JSON保存appのsource-free artifactを検証する。標準ライブラリは5契約テスト。

公開module API baselineとLinux CIを追加した。CIは回帰テスト、stdlib契約、SDK組立てとAPI breaking diffを検査する。今回の作業で確認するのはlocal Linuxの実行結果であり、GitHub上のCI結果はpush後の実行に従う。

bool/短いoption/help、path/storageの追加契約、process lock/migration、CSV/日時/decimal、HTTP/DB/UIは未実装。主要なアルゴリズムlibrary、streaming入力、collectionの複製費用改善と検証順序は[v0.9.3草案](REWIND_v0.9.3.md)へまとめた。現在のList/Mapを大規模入力で必要な計算量を満たすと表示しない。
