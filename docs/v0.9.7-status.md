# REWIND v0.9.7 実装状況

2026-10-01。compiler/package/language 0.9.7。std.graphにtopological、bellmanFord、components、minimumForest、ancestors/lcaを追加した。

Kahn順序はvertex初期順・adjacency順に従いcycleを拒否する。Bellman-Fordはsourceから到達するnegative cycleとdistance overflowを区別する。SCCは再帰を使わないKosarajuでdense component IDを返す。minimumForestは各directed edgeをundirected候補としてKruskalで処理し、weight・component数・採用edgeを返す。重複edgeや負weightを許し、加算はchecked。

ancestorsは最大4,096 vertexのdirected rooted treeを検証し、binary lifting用tableを作る。lcaはrange検査とdepth調整を行う。graph全体の既存上限は65,536 vertex/edge。SCC/topologicalはO(V+E)の走査、Bellman-FordはO(VE)、forestはO(E log E)、ancestorsはO(V log V)。実際のList操作はpaged tree費用を伴う。

3vertex directed graphの64通りをBFSの相互到達性と照合し、負辺/cycle/forest、LCAの祖先・同vertex・rangeを検証した。graph fieldはまだ公開でconstructor不変条件をcallerが維持する。max flow/min-cost flow、matchingなどは後続項目。
