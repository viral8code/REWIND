# REWIND v0.9.3 実装状況

更新日: 2026-10-01。compiler/package 0.9.3、language 0.9.3。作業branchは`codex/develop`。[草案](REWIND_v0.9.3.md)の初回完了条件「AとFenwick/segment tree・BFS/Dijkstra」を採用する。

## storageと型

TypedListとheapをpersistent paged treeへ変更した。root cloneはO(1)、get/set/push/popはO(log(max(1,n/64)))のtree探索。更新はpathと最大64slotの参照を複製する。payloadもArcで保持し、隣接heap object全体を複製しない。BytesのcloneもO(1)で、slice/decodeは出力の大きさに従う。wireのList/Bytes/heap形式を維持し、compiler版はexactに更新する。

heapのlogical byte totalをrootで集計し、budget検査で全heapを毎回走査しない。Checkpointは旧rootを保持し、heap update/allocのbudget失敗でroot/IDを復元する。歴史のlogical bytesはrootごとの保守的な計数であり、physical resident memoryを正確に表示する方式ではない。Mapのget/lenは全体cloneを避ける。primitive Map更新のpayload cloneとuser Ord Mapの線形探索は残る。

importした型をgeneric constructorに渡す名前解決、selected importの明示generic callのvisibility、ShareなOption/Result constructor、検査済み関数が借用から新ownerを返す契約を補修した。borrow-derived mutable payloadの直接return、read-only borrowからのpopは拒否する。List.pop()->Option<T>はlanguage0.9.3。generic call cacheはcallee/type/globalのinterface stampを一度計算し、依存の型変更で無効化する。

## source library

既存12moduleにsort/search/sequence、heap/deque/disjointSet、integer/modular、fenwick/segment/graph、scanner/pathの13moduleを追加した。

- stable merge sort/inPlace、lower/upper/binary search、reverse/rotate/unique/compression/prefix/permutation
- callbackによるmin/max heap、bounded ring deque、path compression+union by sizeのDSU
- checked add/multiply、gcd/lcm/extendedGcd、prime sieve/factorization/combination、mod normalize/add/multiply/power/inverse
- overflowをpreflightするFenwick update、orderを保持するgeneric monoid segment tree
- compact adjacency、BFS/iterative DFS、lazy heap Dijkstra。未到達、負辺、距離overflowを区別
- bounded Bytes cursorによるtoken/整数scanner。input observationはappで行う
- argsのbool/short option/required schema/help、String-key Map entries/update、lexical relative path/join

所有権・容量・計算量・失敗は[ライブラリ一覧](../libraries/README.md)。mutable structのfieldは現在公開され、constructorが作った形を直接壊さないことをcallerの契約とする。callbackのpanicまでoperation全体をatomicにする保証を追加しない。

## SDK・例・検証

SDKのlanguage/std metadataを0.9.3へ更新し、25moduleのsource/doc/API snapshotを同梱する。導入先はdevelopment language0.9.3 project。署名domain、stdのlock/trust、改変/衝突/symlink拒否を維持する。sum/JSON保存例に加え[最短距離CLI](../examples/v093/README.md)を同梱する。

既存173件にstorage3件と統合5件を追加し、計181件のRust回帰テストを検証する。storage単体試験では4,096/8,192/16,384要素の更新でpath/slot copyの増大が有界であることとsnapshot共有を検査する。logical予算と失敗復元、既存runtimeのCheckpoint/観測/publishを回帰検証する。source libraryは10契約テスト。追加統合試験は整列/探索と数値境界、短距離の参照実装との照合、DSU/Fenwick/deque/heapのCheckpoint、借用拒否、byte scanner、record/replay/source-free artifactを確認する。SDK署名・再現性・production asset/releaseも検証する。

v0.9.3のsource/Rust APIでTypedList/Bytes/State.heapの内部storage型が変わる。Rust embedding APIの安定性を約束する版ではない。language0.2〜0.9.2を保持するが、lock/artifact/replayはcompiler0.9.3へのupdate/rebuild/再記録が必要。
