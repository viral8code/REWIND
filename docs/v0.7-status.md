# REWIND v0.7 実装状況

更新日: 2026-09-30。Rust パッケージ版 0.7.0。`language = "0.7"` で v0.6 の機能と以下の採用機能を使う。

## 不変データと純粋な定数

```rewind
record Point{x:Int,y:Int}
fn twice(n:Int)->Int effects {}{return n*2;}
pub const FOUR:Int=twice(2);
let p=Point(FOUR,3);
match p{Point{x:n,y:_}=>{assert_eq(n,4);}}
```

record は値として保存し、全フィールドに Share を要求する。可変 collection は Frozen にする。enum の Share は全 payload から判定する。record のフィールド代入と generic record は拒否する。後者はフィールド契約が未確定のためである。既存のフィールド move・借用・Checkpoint 復元を継承し、v0.7 の到達不能 match arm はエラーになる。

const は型・純粋性・Share を検査し、既に定義した const と純粋な関数を使って検査時に評価する。Checkpoint/cleanup/runtime 境界と通常の可変 globals は使えない。評価は合計 100,000 手順、履歴 memory/storage は各 4 MiB。失敗は ConstEvaluationFailed として報告する。型展開・単相化は既存の予算を使う。成果物には元の式を保持し、実行時も同じ式を評価する（定数式への IR 置換は行わない）。

## 合成 property generator

`property(seed,cases,generator,shrinker,predicate)->Result<Unit,PropertyCase<T>>`。generator は `fn(Int)->T`、shrinker は `fn(T)->T`、predicate は `fn(T)->Bool`。全 callback に純粋性と Send/Share 捕捉を要求し、T に Share を要求する。tuple、record、enum、String、Frozen などを組み合わせられる。

SplitMix64 の signed Int を generator へ渡す。最大 100,000 case。失敗入力から shrinker を最大 64 回呼び、同値・循環・成功候補で止める。大域最小は保証しない。PropertyCase は seed/case/input/shrinks を持つ。記録の audit に seed、縮小済み入力と位置を保存し、秘密値は終了時に再度伏せる。再生は通常の命令列と結果検査を行う。整数専用 propertyInt も利用できる。

## 公開 API と文書

```sh
rewind api-snapshot --root DIR --output before.json
rewind api-diff before.json after.json --deny-breaking
rewind doctest manual.md --root DIR
rewind timeline session.json --from 0 --count 100 --task 0
```

snapshot は root module の public 関数・型・trait・alias・const を保存する。効果、所有権、捕捉、失敗型、trait の既定本体、const の式を契約に含める。関数の引数名・通常の本体・位置だけの変更は含めない。削除と契約変更は保守的に breaking、追加は nonbreaking。API format 1 は compiler 版に依存しない。各入力 8 MiB まで。

doctest は Markdown の独立した ```rewind fence を検査・実行する。各 example の仮想 runtime は新しく、publish も Host を変更しない。manifest の署名・lock・effects は通常通り検証する。文書 1 MiB、256 example まで。Host 読み取りは root 内の fixture を使える。標準入力・外部環境に依存する example は避ける。

timeline は記録 index から task 状態、原因木、audit、仮想ファイル差分を JSON で返す。ソースや秘密の再供給は不要。VM は実行しない。trace 128 MiB、1 回 1,000 event まで。署名検証付き対話表示は既存 debug-session --public-key を使う。

artifact format 2、trace format 1、secure lock format 2 は exact compiler 0.7.0。cache は実装ハッシュ一致を要求する。他版の artifact/replay は再 build/record が必要。
