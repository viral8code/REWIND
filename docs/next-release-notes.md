# 次のリリースに入る変更（未リリース）

4.1.0 のあと、オセロの利用者からの報告をもとに入れた変更です。版は上げていません。

## 追加

- `Int` のビット演算子 `&`、`|`、`^`、`<<`、`>>`。優先順位は Rust と同じです。`<<=` と `>>=` はありません。
- 一時的な値の借用。`total(&List<Int>())` のように、関数の呼び出しの結果やリテラルを `&` で貸せます。
- GUI: `ellipse`（円・楕円）、`setBounds`、`setColor`、`waitEvent`（時間つきの入力待ち）。

## 直したこと

- GC の費用を、ネイティブ処理量とは別の枠で数えます。枠の大きさは同じで、生きている値が多いプログラムが、GC のせいでネイティブ処理量を使い切ることはありません。GC が止まらない暴走は、別の枠で止まります（`NativeWorkBudgetExceeded: collection`）。
- 整数のリテラルだけで書いた `match`（4 本以上のアーム、ガードなし）は、表を引いて分岐します。
- GUI のアプリを `--record` で記録して、状態の索引が 16 MiB を超えたとき、プログラムを止めずに索引を捨てます。

## まだ対応していないこと

- インタプリタ自体の速度。
- 描画イベントによる自前の描画。
