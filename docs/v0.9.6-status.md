# REWIND v0.9.6 実装状況

2026-10-01。compiler/package/language 0.9.6。stdに4moduleを追加した。

| module | API | 容量・契約 |
|---|---|---|
| stringSearch | prefix / kmp / z | Bytesで最大65,536 byte、byte offset、exact matching、空patternは全境界 |
| bitset | create / get / set / count / union / intersection / shifted | 最大65,536 bit、63-bit word、dimension検査 |
| range | sparseMin / minimum | 最大4,096要素、半開区間、空query拒否 |
| rollbackSet | create / root / same / mark / unite / rollback | 最大65,536要素/変更、union by size、path compressionなし |

KMP/Z/prefixの比較回数は線形、Listアクセスにpaged tree費用がかかる。sparseMinはO(n log n)個の要素、queryは2要素とlog/widthの計算。rollbackSetのrootはO(log n)、rollbackは変更数に従う。bitsetのshiftはbit単位の走査で高速なword shift専用実装ではない。markは現在の履歴長であり、分岐を越えるopaque tokenではない。

mutable struct内のList.popを型検査できるようにした。read-only owner borrowでfieldをpopする拒否例を含め、byte検索をnaive参照と照合し、区間query、word境界、rollback不変条件を検証した。private field、lazy segment tree、suffix arrayなどは継続項目。
