# REWIND v0.9.5 実装状況

2026-10-01。compiler/package/language 0.9.5。codex/developで継続する。

file write/append/truncate/delete/copy/move、directory create/delete/move、handle writeのpending state・操作ID・handle位置をtransactionとして復元する。incremental publish modeでは操作ID付与後にも予算を検査し、metadata課金失敗でdeltaを残さない。観測は実Hostを読んだ事実として保持する。

virtual publish後のdirectory treeを走査・move・deleteできる。Hostと仮想deltaを統合して判定し、実Hostに作成されていないtreeのmoveも扱う。予算失敗のstate digest一致、仮想treeの確定→move→deleteと実disk不変を追加試験した。既存CLI/publish/stream回帰も成功した。

v0.9.4以降の増分publish/byte input契約を0.9.5〜0.9.9のmodeへ維持する。SDK metadataはcompiler版と連動する。草案全体の完了ではない。heap回収・physical/native budget、private field/複数bound、typed error統合などは後続の実装と継続計画で追跡する。
